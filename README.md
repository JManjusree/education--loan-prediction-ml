# Education Loan Prediction using Machine Learning

# Project Overview
This project predicts whether education loan application will be approved based on student and financial factors such as applicant income,coaaplicant income,CIBIL score,cgpa,previous academic performance and requested loan amount.

The project uses a machine learning approach to classify loan applications as approved or rejected based on eligibilty criteria.
# Features
- Generated a synthetic education loan dataset
- Data preprocessing and Cleaning
- Exploratory Data Analysis
- Loan Approval Prediction
- Model training and Prediction
- Classification of loan status
